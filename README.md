# Бои Тапков

Idle-игра на Flutter: прокачивай боевой тапок и сражайся 1×1 с тапками других игроков.
Тапки — PNG-спрайты, аксессуары прокачки и UI рисуются кодом.

## Запуск

```
flutter pub get
flutter run -d chrome     # быстрая отладка в браузере
flutter run               # Android-устройство / эмулятор
flutter test              # тесты боевого движка
```

## Как добавить тапок

1. Нарисовать PNG: прозрачный фон, вид сбоку, **носок вправо**, без лица.
   Пропорция 2:1, рекомендуемый размер **1200×600** (600×300 сойдёт для черновика).
   Подошва у всех тапков на одной высоте — тогда они ровно стоят на коврике.
2. Положить файл в `assets/slippers/<id>.png`.
3. Добавить запись в `SlipperCatalog.all` (`lib/game/slipper_kind.dart`): имя, редкость,
   бонусы и якоря — точки в долях ширины/высоты картинки (0..1), куда вешаются
   аксессуары прокачки: `ridge` (верхний контур, шипы), `side` (бок, пластины и бинты),
   `heel` (пламя), `sole` (полоса подсветки подошвы).
4. Проверить якоря:
   `flutter test test/tools/preview_sprites_test.dart --dart-define=OUT=<папка>` —
   в папке появятся PNG каждого тапка с накладками на 1, 15 и 30 уровнях.

## Структура

- `lib/game/` — чистый Dart без Flutter: статы тапка, экономика, ELO, детерминированный
  боевой движок (`BattleSim`), генератор соперников (заглушка сервера), состояние игры.
- `lib/game/slipper_kind.dart` — каталог тапков: редкость, бонусы, якоря аксессуаров.
- `lib/ui/slipper_sprite.dart` — спрайт тапка: PNG + накладки прокачки + эффекты боя.
- `lib/ui/` — тема, игровые виджеты (панели, кнопки, бары), экраны.
- `assets/slippers/` — PNG тапков.
